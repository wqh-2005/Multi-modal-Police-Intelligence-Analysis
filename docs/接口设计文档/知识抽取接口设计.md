# 警务研判项目——知识抽取模块接口文档（模块二）

> 数据流位置：**格式 1.2（多模态识别输出）→ 格式 1.3（知识抽取输出）**
> 消费方：模块三（知识存储）。字段定义详见《知识抽取与存贮数据结构与字段说明.md》。

## 输入（格式 1.2）

==由模块一（/multimodal/analyze）产出，作为本模块请求体==

```json
{
  "case_id": "string",
  "outputs": [
    {
      "text": "string",
      "type": "text|image|audio|video",
      "deepfake_result": true,
      "confidence": 0,
      "status": "done|error",
      "processing_time_ms": 0
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `case_id` | `string` | 是 | — | 案件编号，贯穿全流程 |
| `outputs` | `OutputItem[]` | 是 | — | 多模态识别结果列表 |
| `outputs[].text` | `string` \| `null` | 否 | `"此文本为空"` | 识别出的文本内容 |
| `outputs[].type` | `"text"` \| `"image"` \| `"audio"` \| `"video"` | 是 | — | 模态类型 |
| `outputs[].deepfake_result` | `bool` \| `null` | 否 | `null` | AI 换脸检测结果，`null` = 未检测 |
| `outputs[].confidence` | `float` \| `null` | 否 | `null` | 识别置信度 [0, 1]，不可用时为 `null` |
| `outputs[].status` | `string` | 否 | `"pending"` | 处理状态：`done`（成功）/ `error`（失败） |
| `outputs[].processing_time_ms` | `int` | 否 | `0` | 该条识别耗时（毫秒） |

> **文本合并规则**：API 仅合并 `status == "done"` 且 `text` 非空、且不等于 `"此文本为空"` 的项。
> 兼容说明：早期数据集（`sample/test.json` 等）使用 `"success"`，同样被接受。

## 输出（格式 1.3）

```json
{
  "triplets": [
    {
      "subject": "string",
      "relation": "string",
      "object": "string",
      "subject_type": "string|null",
      "object_type": "string|null"
    }
  ],
  "raw_text": "string",
  "extraction_confidence": 0.0,
  "case_id": "string",
  "deepfake_alert": false,
  "elapsed_ms": 0
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `triplets` | `Triplet[]` | 是 | 三元组列表（LLM 从合并文本中抽取） |
| `raw_text` | `string` | 是 | 合并后的原始输入文本 |
| `extraction_confidence` | `float` | 是 | LLM 自评估置信度 [0, 1] |
| `case_id` | `string` | 否 | 案件编号，回显输入 |
| `deepfake_alert` | `bool` | 否 | 输入中任一 `deepfake_result == true` 则告警 |
| `elapsed_ms` | `float` | 是 | 接口处理耗时（毫秒） |

### Triplet 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `subject` | `string` | 是 | 头实体名称 |
| `relation` | `string` | 是 | 关系类型（如：冒充、转账、拉入群聊、要求下载） |
| `object` | `string` | 是 | 尾实体名称 |
| `subject_type` | `string` \| `null` | 否 | 头实体类型（LLM 推断） |
| `object_type` | `string` \| `null` | 否 | 尾实体类型（LLM 推断） |

#### 实体类型枚举

| 类型 | 含义 | 示例 |
|------|------|------|
| `PERSON` | 人名/角色 | 报警人、案犯甲、客服人员 |
| `ORGANIZATION` | 机构/公司 | XX公安局、XX传媒有限公司 |
| `PLATFORM` | 平台/APP/群聊 | 乐橙APP、微信群 |
| `PHONE` | 手机号 | 13812345678 |
| `ACCOUNT` | 银行账户/社交账号 | 中国农业银行 6228**** |
| `AMOUNT` | 金额 | 66000元、5万元 |
| `ID_CARD` | 身份证号 | 3201**********1234 |
| `URL` | 链接 | http://kuaidi-buchang.com |
| `TIME` | 时间 | 2022-11-14 22:00 |
| `LOCATION` | 地点 | 江苏省南京市 |
| `OTHER` | 其他 | 验证码、二维码、安装包 |

## 接口

### POST /api/v1/knowledge/extract

知识抽取接口：接收模块一的多模态识别结果（格式 1.2），合并有效文本后调用 LLM 抽取三元组（格式 1.3）。

## 错误返回

| 错误场景 | HTTP 状态码 | error_type | 说明 |
|----------|-------------|------------|------|
| 所有有效文本均为空 | `400` | — | `detail: "所有模态输出文本均为空，无法抽取"` |
| LLM 调用超时/上游不可用 | `502` | `LLM_TIMEOUT` | 大模型调用超时，请稍后重试 |
| 抽取过程内部异常 | `500` | `EXTRACTION_ERROR` | 知识抽取失败，`detail` 含错误信息 |
