# 警务研判项目——知识图谱存储模块接口文档（模块三）

> 数据流位置：**格式 1.3（知识抽取输出）→ 格式 1.4（知识存储输出）**
> 输入为模块二产出，输出供模块四（智能研判）消费。字段定义详见《知识抽取与存贮数据结构与字段说明.md》。

## 输入（格式 1.3）

==由模块二（/api/v1/knowledge/extract）产出，作为本模块请求体==

```json
{
  "triplets": [
    {
      "subject": "string",
      "relation": "string",
      "object": "string",
      "subject_type": "string|null",
      "object_type": "string|null"
    }
  ],
  "raw_text": "string",
  "extraction_confidence": 0.0,
  "case_id": "string",
  "deepfake_alert": false
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `triplets` | `Triplet[]` | 是 | 三元组列表 |
| `raw_text` | `string` | 是 | 原始输入文本（写入 `chat_history`，截断至约 800 字） |
| `extraction_confidence` | `float` | 是 | 抽取置信度 [0, 1] |
| `case_id` | `string` | 否 | 案件编号 |
| `deepfake_alert` | `bool` | 否 | AI 换脸告警 |

## 输出（格式 1.4）

```json
{
  "victim": {
    "name": "string",
    "age": 0,
    "profession": "string",
    "phone": "string|null",
    "id_card": "string|null"
  },
  "suspect": {
    "name": "string",
    "phone": "string|null",
    "account": "string|null"
  },
  "relations": [
    { "from": "string", "type": "string", "to": "string" }
  ],
  "transactions": [
    { "from": "string", "to": "string", "amount": 0.0, "time": "string|null" }
  ],
  "chat_history": "string",
  "deepfake_alert": false,
  "case_id": "string",
  "elapsed_ms": 0
}
```

### 字段说明

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `victim` | `Victim` | 是 | — | 受害者信息（启发式推断） |
| `suspect` | `Suspect` | 是 | — | 嫌疑人信息（启发式推断） |
| `relations` | `Relation[]` | 是 | — | 实体关系列表（写入 Neo4j 关系边） |
| `transactions` | `Transaction[]` | 是 | — | 资金交易记录 |
| `chat_history` | `string` | 是 | — | 原始文本（截断至约 800 字） |
| `deepfake_alert` | `bool` | 否 | `false` | AI 换脸告警 |
| `case_id` | `string` | 否 | `""` | 案件编号 |
| `elapsed_ms` | `float` | 是 | — | 接口处理耗时（毫秒） |

### Victim / Suspect 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `victim.name` | `string` | `"未知"` | 受害者姓名/角色名 |
| `victim.age` | `int` | `0` | 年龄 |
| `victim.profession` | `string` | `"未知"` | 职业 |
| `victim.phone` | `string` \| `null` | `null` | 手机号 |
| `victim.id_card` | `string` \| `null` | `null` | 身份证号 |
| `suspect.name` | `string` | `"未知"` | 嫌疑人姓名/角色名 |
| `suspect.phone` | `string` \| `null` | `null` | 手机号 |
| `suspect.account` | `string` \| `null` | `null` | 银行账户 |

### Relation 字段说明

| 字段 | JSON 键 | 类型 | 说明 |
|------|---------|------|------|
| `from_entity` | `from` | `string` | 来源实体名称 |
| `type` | `type` | `string` | 关系类型（作为 Neo4j 关系边类型） |
| `to_entity` | `to` | `string` | 目标实体名称 |

### Transaction 字段说明

| 字段 | JSON 键 | 类型 | 默认值 | 说明 |
|------|---------|------|--------|------|
| `from_entity` | `from` | `string` | — | 转出方 |
| `to_entity` | `to` | `string` | — | 转入方 |
| `amount` | `amount` | `float` | — | 转账金额（元） |
| `time` | `time` | `string` \| `null` | `null` | 交易时间（ISO 8601） |

## 接口

### GET /api/v1/knowledge/health

健康检查：服务存活状态 + Neo4j 连通性。

```json
{ "status": "ok", "service": "knowledge-extraction", "neo4j_connected": true }
```

### POST /api/v1/knowledge/store

知识存储接口：接收三元组（格式 1.3），推断受害者/嫌疑人、构建关系与交易记录，写入 Neo4j 图数据库，返回格式 1.4。

### POST /api/v1/knowledge/pipeline

端到端流水线：一步完成 抽取 + 存储（格式 1.2 → 1.4），输入同模块二（格式 1.2），输出同本模块（格式 1.4 + `elapsed_ms`）。

## 错误返回

| 错误场景 | HTTP 状态码 | error_type | 说明 |
|----------|-------------|------------|------|
| Neo4j 不可达 | `502` | `NEO4J_UNAVAILABLE` | 图数据库服务未启动或连接失败 |
| 存储过程内部异常 | `500` | `STORAGE_ERROR` | 知识存储失败，`detail` 含错误信息 |
| pipeline：文本为空 | `400` | — | `detail: "所有模态输出文本均为空"` |
| pipeline：LLM 超时 | `502` | — | `detail: "LLM 调用超时"` |
| pipeline：其他异常 | `500` | — | `detail: "流水线处理失败: {原因}"` |

## Neo4j 图模型

- **节点**：按实体类型建标签（如 `PERSON`、`AMOUNT`），`MERGE` 按 `name` 去重，新建节点带 `created_at` 时间戳
- **关系边**：关系类型为三元组 `relation` 字段（非法字符自动过滤），`MERGE` 防重复
- **查询示例**：`MATCH (n)-[r]->(m) WHERE n.name CONTAINS '报案人' RETURN n.name, type(r), m.name`
