# 多模态识别与检测接口设计

### 1. 职责边界

- **负责人**：开发人员 A
- **输入**：用户原始数据 (格式 1.1)
- **输出**：多模态识别结果 (格式 1.2)
- **下游对接**：其输出将直接作为 **开发人员 B（知识抽取模块）** 的输入。

### 2. 外部访问接口 (API 层)

用于前端调用或测试脚本触发。

- **路径**：POST /api/v1/multimodal/recognize
- **请求体**：

```
{
  "input_type": "image",
  "content": "Base64...",
  "file_path": "/tmp/img.jpg"
}
```

### 3. 内部协作契约 (实现后端并行的关键)

为了让 **开发人员 B** 和 **开发人员 C** 不需要等 A 写完算法就能开工，我们必须在代码层面固定 **“交接棒”** 的样子。

#### 3.1 共享模型定义 (app/models/multimodal_schema.py)

**这是 A、B、C 三人都要引用的文件。**

```
from pydantic import BaseModel
from typing import Optional

class MultimodalOutput(BaseModel):
    """
    这是模块一产生的‘交接棒’对象
    开发人员 A：必须生成这个对象
    开发人员 B：以此对象作为函数的输入
    """
    text: str              # 识别出的文字
    source_type: str       # 原始类型
    deepfake_result: Optional[bool]  # 是否伪造
    confidence: float      # 置信度
    case_id: str           # 案件ID (贯穿全流程)
```
