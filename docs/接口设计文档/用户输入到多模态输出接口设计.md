# 用户输入到多模态输出接口设计

### 多模态识别接口设计 (Multimodal Recognition API)

#### 1. 接口描述

该接口用于接收用户输入的原始数据（文本、图像、音频或视频），进行多模态识别处理，提取其中的文本信息并进行深度伪造（Deepfake）检测。

- **请求方式**：POST
- **接口路径**：/api/v1/multimodal/recognize
- **数据格式**：application/json

------



#### 2. 请求参数 (对应格式 1.1)

| 字段名     | 类型   | 必填 | 默认值   | 说明                                                         |
| ---------- | ------ | ---- | -------- | ------------------------------------------------------------ |
| input_type | string | 是   | 无       | 可选值："text", "image", "audio", "video"                    |
| content    | string | 是   | 无       | **text类型**：具体文本内容；**其他类型**：存放 Base64 编码后的二进制数据 |
| file_path  | string | 否   | null     | 用户上传文件时，存放的本地路径                               |
| timestamp  | string | 否   | 当前时间 | 请求发起的时间戳                                             |

**请求示例 (以图像输入为例)：**

```
{
  "input_type": "image",
  "content": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8/5+hHgAHggJ/PchI7wAAAABJRU5ErkJggg==",
  "file_path": "/tmp/upload/img_001.jpg",
  "timestamp": "2024-05-20T10:00:00+08:00"
}
```

------



#### 3. 响应参数 (对应格式 1.2)

接口返回应遵循文档第8部分的通用结构，将格式 1.2 的数据放在 data 字段中。

| 字段名             | 类型      | 必填 | 默认值       | 说明                                               |
| ------------------ | --------- | ---- | ------------ | -------------------------------------------------- |
| text               | string    | 是   | "此文本为空" | 提取或识别后的文本内容                             |
| source_type        | string    | 是   | 无           | 原始输入的类型 (对应请求的 input_type)             |
| deepfake_result    | bool/null | 是   | null         | true: 检测到换脸; false: 正常; null: 不适用/未检测 |
| confidence         | float     | 否   | null         | 识别置信度 (0.0 - 1.0)                             |
| processing_time_ms | int       | 否   | 0            | 处理耗时（毫秒）                                   |

**响应示例：**

```
{
  "code": 200,
  "message": "success",
  "data": {
    "text": "提取到的语音/图片文字内容...",
    "source_type": "image",
    "deepfake_result": false,
    "confidence": 0.98,
    "processing_time_ms": 1234
  }
}
```

------



### 开发注意事项（基于文档要求）：

1. **输入校验**：必须严格检查 input_type 是否在枚举值（text/image/audio/video）范围内。
2. **Base64 处理**：如果 input_type 不是 text，后端需要具备对 content 字段进行 Base64 解码的能力。
3. **Deepfake 逻辑**：
   - 如果输入是纯文本 (text)，deepfake_result 通常应返回 null（不适用）。
   - 如果是图像或视频，必须返回布尔值结果。
4. **后续对接**：该接口输出的 text 内容，将作为下一个模块 **“知识抽取 (格式 1.3)”** 的核心输入，请确保识别出的文本质量。
