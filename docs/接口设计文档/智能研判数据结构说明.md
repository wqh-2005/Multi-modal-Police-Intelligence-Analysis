# 智能研判与预警输出 — 数据结构说明

> 模块四（智能研判）接收上游知识图谱数据（格式 1.4），输出研判结果与预警列表（格式 1.5）。

---

## 一、输入模型（上游 → 智能研判）

### 1.1 GraphStorageOutput（格式 1.4）

知识图谱存储模块的输出，作为智能研判的输入。

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `case_id` | `str` | 是 | `""` | 案件编号 |
| `victim` | `Victim` | 是 | — | 受害者信息 |
| `suspect` | `Suspect` | 是 | — | 嫌疑人信息 |
| `relations` | `List[Relation]` | 是 | — | 实体关系列表 |
| `transactions` | `List[Transaction]` | 是 | — | 资金交易记录列表 |
| `chat_history` | `str` | 是 | — | 原始聊天记录（截断至 500 字） |
| `deepfake_alert` | `bool` | 否 | `false` | 是否触发 AI 换脸警告 |

**JSON 示例**：

```json
{
  "case_id": "CASE-001",
  "victim": {
    "name": "张先生",
    "age": 45,
    "profession": "公司职员",
    "phone": "13800001111",
    "id_card": "310101199001011234"
  },
  "suspect": {
    "name": "A",
    "phone": null,
    "account": null
  },
  "relations": [
    { "from": "A", "type": "冒充", "to": "XX市公安局" },
    { "from": "A", "type": "威胁", "to": "张先生" },
    { "from": "A", "type": "要求转账", "to": "张先生" },
    { "from": "张先生", "type": "转账", "to": "200万元" }
  ],
  "transactions": [
    { "from": "张先生", "to": "安全账户", "amount": 380000, "time": "2026-01-15T10:30:00" }
  ],
  "chat_history": "A：您好，这里是XX市公安局刑侦支队...",
  "deepfake_alert": false
}
```

---

### 1.2 Victim（受害者信息）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `name` | `str` | 否 | `"未知"` | 受害者姓名 |
| `age` | `int` | 否 | `0` | 受害者年龄 |
| `profession` | `str` | 否 | `"未知"` | 受害者职业 |
| `phone` | `Optional[str]` | 否 | `null` | 受害者手机号 |
| `id_card` | `Optional[str]` | 否 | `null` | 受害者身份证号 |

**JSON 示例**：

```json
{
  "name": "张先生",
  "age": 45,
  "profession": "公司职员",
  "phone": "13800001111",
  "id_card": "310101199001011234"
}
```

---

### 1.3 Suspect（嫌疑人信息）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `name` | `str` | 否 | `"未知"` | 嫌疑人姓名 |
| `phone` | `Optional[str]` | 否 | `null` | 嫌疑人手机号 |
| `account` | `Optional[str]` | 否 | `null` | 嫌疑人银行账户 |

**JSON 示例**：

```json
{
  "name": "A",
  "phone": null,
  "account": null
}
```

---

### 1.4 Relation（实体关系）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `from` | `str` | 是 | — | 来源实体名称 |
| `type` | `str` | 是 | — | 关系类型（如：冒充、威胁、转账、要求下载等） |
| `to` | `str` | 是 | — | 目标实体名称 |

**JSON 示例**：

```json
{
  "from": "A",
  "type": "冒充",
  "to": "XX市公安局"
}
```

---

### 1.5 Transaction（资金交易）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `from` | `str` | 是 | — | 转出方 |
| `to` | `str` | 是 | — | 转入方 |
| `amount` | `float` | 是 | — | 转账金额（元） |
| `time` | `Optional[str]` | 否 | `null` | 交易时间（ISO 8601 格式） |

**JSON 示例**：

```json
{
  "from": "张先生",
  "to": "安全账户",
  "amount": 380000,
  "time": "2026-01-15T10:30:00"
}
```

## 二、内部转换模型（格式 1.4 → 研判输入）

> GraphStorageOutput 通过 `_convert_to_neo4j()` 函数转换为 Neo4jData，供研判模块使用。

### 2.1 Neo4jData

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `case_id` | `str` | 否 | `"未知"` | 案例唯一标识 |
| `victim_info` | `VictimInfo` | 否 | `VictimInfo()` | 受害人信息 |
| `suspect_info` | `SuspectInfo` | 否 | `SuspectInfo()` | 嫌疑人信息 |
| `relationships` | `List[RelationshipInfo]` | 否 | `[]` | 关系信息列表 |
| `transactions` | `List[TransactionInfo]` | 否 | `[]` | 交易信息列表 |
| `chat_history` | `str` | 否 | `""` | 聊天记录 |
| `deepfake_alert` | `bool` | 否 | `false` | 是否存在 AI 换脸嫌疑 |

---

### 2.2 VictimInfo（受害人信息）

| 字段 | 类型 | 必填 | 默认值 | 可选值 | 说明 |
|------|------|------|--------|--------|------|
| `name` | `str` | 否 | `"未知"` | — | 受害人姓名，空值自动转为"未知" |
| `age` | `int` | 否 | `0` | ≥0 | 受害人年龄 |
| `profession` | `str` | 否 | `"未知"` | — | 受害人职业，空值自动转为"未知" |
| `phone` | `Optional[str]` | 否 | `null` | — | 受害人电话号码 |
| `id_card` | `Optional[str]` | 否 | `null` | — | 受害人身份证号 |

---

### 2.3 SuspectInfo（嫌疑人信息）

| 字段 | 类型 | 必填 | 默认值 | 可选值 | 说明 |
|------|------|------|--------|--------|------|
| `name` | `str` | 否 | `"未知"` | — | 嫌疑人姓名，空值自动转为"未知" |
| `age` | `int` | 否 | `0` | ≥0 | 嫌疑人年龄 |
| `amount` | `str` | 否 | `"未知"` | — | 嫌疑人银行账户，空值自动转为"未知" |

---

### 2.4 RelationshipInfo（关系信息）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `from` | `str` | 否 | `"未知"` | 关系起点，空值自动转为"未知" |
| `type` | `str` | 否 | `"未知"` | 关系类型，空值自动转为"未知" |
| `to` | `str` | 否 | `"未知"` | 关系终点，空值自动转为"未知" |

---

### 2.5 TransactionInfo（交易信息）

| 字段 | 类型 | 必填 | 默认值 | 可选值 | 说明 |
|------|------|------|--------|--------|------|
| `from` | `str` | 否 | `"未知"` | — | 转出方，空值自动转为"未知" |
| `to` | `str` | 否 | `"未知"` | — | 转入方，空值自动转为"未知" |
| `amount` | `float` | 否 | `0.0` | ≥0 | 交易金额（元），支持 `"380000元"` 等格式自动解析 |
| `time` | `Optional[str]` | 否 | `null` | — | 交易时间，ISO 格式 |

## 三、输出模型（智能研判 → 预警输出）

### 3.1 JudgmentResult（研判结果，格式 1.5）

| 字段 | 类型 | 必填 | 默认值 | 可选值 | 说明 |
|------|------|------|--------|--------|------|
| `case_id` | `str` | 是 | — | — | 案例唯一标识 |
| `is_fraud` | `bool` | 否 | `false` | `true` / `false` | 是否遭受诈骗 |
| `fraud_type` | `str` | 否 | `""` | 见下方诈骗类型枚举 | 诈骗类型，非诈骗时为空字符串 |
| `confidence` | `str` | 否 | `"低"` | `"高"` / `"中"` / `"低"` | 置信度等级 |
| `confidence_score` | `float` | 否 | `0.0` | 0.0 ~ 1.0 | 置信度分数 |
| `reason` | `str` | 否 | `""` | — | 研判理由，说明判断依据 |
| `warning` | `str` | 否 | `""` | — | 预警建议，如"请拨打 96110" |
| `deepfake_alert` | `bool` | 否 | `false` | `true` / `false` | 是否检测到 AI 换脸 |
| `similar_cases` | `List[SimilarCase]` | 否 | `[]` | — | 相似案例列表 |
| `timestamp` | `str` | 是 | — | — | 研判完成时间（ISO 8601 格式） |
| `error` | `Optional[JudgmentError]` | 否 | `null` | — | 研判错误信息，正常时为 null |

**诈骗类型枚举**（`fraud_type` 可选值）：

| 值 | 说明 |
|----|------|
| `""` | 非诈骗 |
| `"冒充公检法及政府机关类"` | 冒充公检法诈骗 |
| `"虚假网络投资理财类"` | 投资理财诈骗 |
| `"刷单返利类"` | 刷单诈骗 |
| `"虚假贷款类"` | 贷款诈骗 |
| `"冒充客服类"` | 冒充客服诈骗 |
| `"杀猪盘类"` | 杀猪盘诈骗 |
| `"其他诈骗类型"` | 其他类型 |

**正常研判 JSON 示例**：

```json
{
  "case_id": "CASE-001",
  "is_fraud": true,
  "fraud_type": "冒充公检法及政府机关类",
  "confidence": "高",
  "confidence_score": 0.96,
  "reason": "嫌疑人冒充XX市公安局刑侦支队人员，以身份证被冒用涉嫌洗钱为由，威胁受害人转账到指定安全账户，符合冒充公检法及政府机关类诈骗的典型特征。",
  "warning": "⚠️ 立即停止转账！公安机关不会通过电话办案，不会设立安全账户。请拨打 96110 报警。",
  "deepfake_alert": false,
  "similar_cases": [
    {
      "content": "案例5：刘女士接到公安局电话，称其涉嫌洗钱，需将资金转入安全账户验证，被骗23万元。",
      "fraud_type": "冒充公检法及政府机关类",
      "score": 0.712
    }
  ],
  "timestamp": "2026-08-11T14:35:00+08:00",
  "error": null
}
```

**异常降级 JSON 示例**（LLM 调用失败时）：

```json
{
  "case_id": "CASE-002",
  "is_fraud": false,
  "fraud_type": "",
  "confidence": "低",
  "confidence_score": 0.0,
  "reason": "",
  "warning": "请通过96110反诈专线进行人工咨询",
  "deepfake_alert": false,
  "similar_cases": [],
  "timestamp": "2026-08-11T14:35:00+08:00",
  "error": {
    "occurred": true,
    "source": "llm_client",
    "message": "API 调用超时"
  }
}
```

### 3.2 JudgmentError（研判错误信息）

| 字段 | 类型 | 必填 | 默认值 | 可选值 | 说明 |
|------|------|------|--------|--------|------|
| `occurred` | `bool` | 否 | `false` | `true` / `false` | 是否发生异常 |
| `source` | `str` | 否 | `""` | `"rag_engine"` / `"llm_client"` / `"data_empty"` | 异常来源模块 |
| `message` | `str` | 否 | `""` | — | 异常描述信息 |

**JSON 示例**：

```json
{
  "occurred": true,
  "source": "llm_client",
  "message": "API 调用超时，请稍后重试"
}
```

### 3.4 Alert（预警信息）

| 字段 | 类型 | 必填 | 默认值 | 可选值 | 说明 |
|------|------|------|--------|--------|------|
| `type` | `str` | 是 | — | `"fraud_warning"` / `"deepfake_warning"` / `"safe_notice"` / `"service_error"` | 预警类型 |
| `level` | `str` | 是 | — | `"高"` / `"中"` / `"低"` | 严重程度 |
| `title` | `str` | 是 | — | — | 预警标题 |
| `message` | `str` | 是 | — | — | 预警核心描述 |
| `warning` | `Optional[str]` | 否 | `null` | — | 紧急建议 |
| `reason` | `Optional[str]` | 否 | `null` | — | 判断理由 |

#### 预警类型说明

**类型一：fraud_warning（诈骗预警）**

```json
{
  "type": "fraud_warning",
  "level": "高",
  "title": "冒充公检法及政府机关类",
  "message": "您正在遭遇冒充公检法及政府机关类。",
  "warning": "⚠️ 立即停止转账！公安机关不会通过电话办案，不会设立安全账户。请拨打 96110 报警。",
  "reason": "嫌疑人冒充公安局人员，以涉嫌洗钱为由要求转账，符合冒充公检法类诈骗特征。"
}
```

**类型二：deepfake_warning（AI 换脸预警）**

```json
{
  "type": "deepfake_warning",
  "level": "高",
  "title": "疑似使用AI换脸技术",
  "message": "检测到视频内容可能使用了AI换脸技术，请注意自身财产安全",
  "warning": null,
  "reason": null
}
```

**类型三：safe_notice（安全提示）**

```json
{
  "type": "safe_notice",
  "level": "低",
  "title": "暂未发现诈骗风险",
  "message": "根据您提供的信息，我们暂未发现明确的诈骗特征，但建议您小心为妙",
  "warning": null,
  "reason": null
}
```

**类型四：service_error（服务异常）**

```json
{
  "type": "service_error",
  "level": "高",
  "title": "研判服务异常",
  "message": "研判服务暂时不可用，请人工介入处理",
  "warning": "请通过96110反诈专线进行人工咨询",
  "reason": "LLM API 调用超时"
}
```

## 五、数据流转总览

```
上游输入（格式 1.4）                   研判输出（格式 1.5）
┌─────────────────────┐              ┌─────────────────────────┐
│ GraphStorageOutput  │   _convert   │  JudgmentResult         │
│  ├─ victim          │   _to_neo4j  │   ├─ is_fraud           │
│  ├─ suspect         │ ──────────→  │   ├─ fraud_type         │
│  ├─ relations       │              │   ├─ confidence         │
│  ├─ transactions    │              │   ├─ reason             │
│  ├─ chat_history    │              │   ├─ warning            │
│  └─ deepfake_alert  │              │   ├─ similar_cases[]    │
└─────────────────────┘              │   ├─ error?             │
                                     │   └─ timestamp          │
                                     ├─────────────────────────┤
                                     │  Alert[]                │
                                     │   ├─ type               │
                                     │   ├─ level              │
                                     │   ├─ title              │
                                     │   └─ message            │
                                     └─────────────────────────┘
```
