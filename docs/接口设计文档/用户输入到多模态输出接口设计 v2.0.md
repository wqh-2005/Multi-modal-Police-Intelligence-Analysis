# 警务研判项目——多模态模块接口文档

## 输入

==timestamp、file_path、file_name是由后端填充的字段==

```json
{
  "case_id": "string",
  "inputs": [
    {
      "type": "text",
      "content": "string",
      "timestamp": "string",
      "file_path": "string",
      "file_name": "string"
    }
  ]
}
```

## 输出

```json
} 
"case_id": "string",
  "outputs": [
    {
      "text": "此文本为空",
      "type": "text",
      "deepfake_result": true,
      "confidence": 0,
      "status": "pending",
      "processing_time_ms": 0
    }
  ]
}
```

## 多模态

| 多模态 | case_id | content        | text                     | type  | deepfake_result | confidence                | status | processing_time_ms |
| ------ | ------- | -------------- | ------------------------ | ----- | --------------- | ------------------------- | ------ | ------------------ |
| 文本   | /       | 文本内容       | 文本内容                 | text  | None(不可用)    | None(不可用)              | done   | /                  |
| 图片   | /       | 图片Base64编码 | 转码并OCR识别后的文本    | image | None(不可用)    | PaddleOCR返回的平均置信值 | done   | /                  |
| 音频   | /       | 音频Base64编码 | 转码并大模型识别后的文本 | audio | None(不可用)    | None(不可用)              | done   | /                  |
| 视频   | /       | 视频Base64编码 | None(不可用)             | video | 是否为ai换脸    | 大模型返回的置信度        | done   | /                  |

## 错误返回

使用outputItem构造

除了case_id不合法==立即返回==，其他都是将错误结果放到**输出列表中**

| 类型错误                        | case_id | content | text                                                     | type | deepfake_result | confidence | status | processing_time_ms |
| ------------------------------- | ------- | ------- | -------------------------------------------------------- | ---- | --------------- | ---------- | ------ | ------------------ |
| 类型超出范围                    |         |         | 不支持的文件类型                                         |      |                 |            | error  |                    |
| case_id不合法(立即返回错误响应) |         |         | 案件ID包含非法字符，请仅使用字母、数字、- : () [] {} _ . |      |                 |            | error  |                    |
| 任何捕获错误                    |         |         | 处理异常: {str(e)                                        |      |                 |            | error  |                    |
