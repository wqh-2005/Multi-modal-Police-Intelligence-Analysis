# 三种方法 200 题对比结果与优化问题

分析日期：2026-11-20。

运行批次：`demo200_full_v1`。

## 1. 本轮结论

文本 RAG 的分类准确率最高，图谱 RAG 的 Macro-F1 最高，直接回答最快。三种方法的准确率仅相差 1 个百分点，当前没有明显拉开差距，不能据此认定某种方法显著优于另外两种。

从本轮准确率、引用情况和耗时综合观察，文本 RAG 暂时略占优势。图谱 RAG 在部分类型上有改善，但整体收益尚不足以体现其额外开销的价值。

本文比较的是同一个回答模型下的三种方法，而非三个不同模型。

完整性检查结果：

注意：本次没有使用 D 独立交付的正式 metadata；参考类别来自 A 原有类别，尚未独立裁定其标注正确性。对运行配置的核对也不等于重新审计了实际数据库与索引的完整覆盖范围。

## 5. 检索带来的纠正与干扰

以直接回答为基准：

| 变化 | 文本 RAG | 图谱 RAG |
| --- | ---: | ---: |
| 直接回答错误，RAG 正确 | 9 题 | 8 题 |
| 直接回答正确，RAG 错误 | 7 题 | 7 题 |
| 净增加正确题数 | 2 题 | 1 题 |

文本 RAG 与图谱 RAG 对比：152 题两者均正确，31 题两者均错误；9 题仅文本 RAG 正确，8 题仅图谱 RAG 正确。

这说明检索既提供帮助，也可能引入干扰。当前没有做显著性检验，不将上述小幅差异描述为显著提升。

### 5.1 q033：两种 RAG 纠正了直接回答

题目涉及冒充支付宝客服、退货退款、取消“百万保障”，并诱导转账。

| A 参考类别 | 直接回答 | 文本 RAG | 图谱 RAG |
| --- | --- | --- | --- |
| 冒充电商物流客服类 | 虚假网络投资理财类 | 冒充电商物流客服类 | 冒充电商物流客服类 |

两种 RAG 均判断正确。文本 RAG 引用了检索证据，图谱 RAG 的证据说明仍为“无”。仅凭改判不能证明模型究竟使用了哪条资料，但它是后续检查检索增益的有效案例。

### 5.2 q023：文本 RAG 引入错误

题目涉及支付论文发表服务费用，之后无法联系对方。

| A 参考类别 | 直接回答 | 文本 RAG | 图谱 RAG |
| --- | --- | --- | --- |
| 虚假购物服务类 | 虚假购物服务类 | 其它类 | 虚假购物服务类 |

文本 RAG 引用了多条资料，却改变了原本正确的类别。后续应检查所引资料与当前问题的相关性，而不能只用“是否存在引用”评价效果。

### 5.3 q078：文本 RAG 出现生成失败

该题文本检索成功，但回答服务返回 HTTP 451，错误码 20021，提示输入可能涉及受限或敏感内容。该条没有生成回答，预测类别为 null。

本轮按失败计入错误。应将服务调用失败与普通类别误判分别统计；不能为提高成绩而直接删除该题。

## 6. 需要优化的问题

### 6.1 C：检索证据没有被充分利用

现象：200 题检索全部成功，但仅 18 条回答明确引用证据；平均上下文约为 B 的 5 倍，生成和检索均更慢。

当前能确认的是引用利用不足，不能仅凭没有引用就断言模型完全没参考上下文。

建议：

1. 检查问题对应的种子节点是否抓住具体诈骗行为，而不是只命中“客服、平台、转账”等泛化概念。
2. 检查邻居扩展后跨案例资料是否偏离问题，避免无关事实占据预算。
3. 改进事实与证据排序，优先提供与问题手法对应的内容，压缩无助于判别的节点 ID 等信息。
4. 区分当前案件中的判定依据与历史参考案例，改进提示词，允许证据不足时明确说明，不能强制编造引用。

### 6.2 C：虚假征信类表现下降

该类直接回答正确 15/20，文本 RAG 正确 16/20，图谱 RAG 仅 11/20。

待验证的原因：图谱检索可能过度关注冒充机构与客服的身份，而弱化注销学生账户、清空贷款额度、更改征信等行为。该解释是排查假设，尚未通过完整消融验证。

建议优先抽查该类错误题的种子、事实、证据和最终判定，核对是否被冒充公检法或客服类资料干扰。

### 6.3 B：虚假购物服务类退化

该类直接回答正确 15/23，文本 RAG 仅 11/23。

建议抽查服务、退款、投资等相邻语义的混淆，尤其关注检索结果是否偏向其它类或返利类，并对 q023 等改错案例逐项复盘。

### 6.4 BC：部分原文中含类别名称

按检索证据文本中是否出现 11 类名称做字符串扫描：B 有 12 道题命中，C 有 2 道题命中。

这一检查只是提示潜在类别标签文字，并不意味着所有命中都是标签，也不代表程序读取了评估金标。例如，先前小样本中曾出现原文开头带括号类别的情况。

建议区分案情自然表述与附加类别标签；对确属附加标注的内容，在统一规则下清理，并分别重建两种知识库，再做对照实验。

### 6.5 评估：尚缺完整的回答质量评分

当前分类指标以 A 类别为参考，引用只核查编号，不评价支持关系。尚未完成防范建议正确性、可执行性、证据忠实度和回答完整性的正式评分。

建议由 D 补齐并核对参考信息，对两种 RAG 和直接回答使用相同标准评分。不能将引用比例当成完整回答质量分数。

## 7. 下一轮实验建议

1. 保留本批次答卷，作为 v1.0 基线，不覆盖旧文件。
2. 优先处理图谱相关性、证据呈现，以及两种知识库中的附加类别标签。
3. 优化阶段固定同一题库、建库范围、回答模型与预算，用新 run_id 比较；每轮尽量只改变一组因素。
4. 记录“改对多少题、改错多少题”，不能只看准确率净变化。
5. D 的正式评估集保持独立。对这 200 道题开展调试后，不再将其成绩作为完全独立的最终测试成绩。
6. 正式报告中同时呈现 Accuracy、Macro-F1、各类别表现、调用失败、证据忠实度、延迟与上下文预算。

## 8. 当前可采用的结论表述

在本轮 200 道案例研判题上，直接回答、文本 RAG 和图谱 RAG 的分类准确率分别为 79.5%、80.5% 和 80.0%。文本 RAG 的准确率略高，图谱 RAG 的 Macro-F1 略高，但三种方法的整体差距较小。图谱 RAG 在冒充电商物流客服和刷单返利类型中表现有所改善，在虚假征信类型中出现退化，并存在较高的上下文开销与较低的显式证据引用比例。当前结果尚不足以支持图谱 RAG 显著优于其他方法，需要继续优化并在独立评估集上验证。
